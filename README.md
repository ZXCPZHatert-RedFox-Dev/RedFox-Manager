
🦊 RedFox Manager (Universal Android Root Control)

Универсальное Android-приложение для мониторинга и управления ядром на любых смартфонах с root-доступом (KernelSU, Magisk, APatch).

Возможности

• 📊 Автоопределение железа: автоматически распознаёт модель смартфона, чипсет (Unisoc, MediaTek, Qualcomm, Exynos), драйвер подсветки, алгоритм ZRAM и TCP BBR.
• ⚡ Профили производительности: мгновенное переключение между RedFox Ultimate (максимальный отклик и BBR), Balanced и Battery Saver.
• ☀️ Поддержка GSI (Phh Treble): автоматическое обнаружение GSI-прошивок и применение фиксов шкалы яркости и программных видеокодеков.
• 🛠️ Меню перезагрузки: быстрый переход в Recovery и Bootloader (Fastboot) в один тап.
